# json-server 라이브러리 환경 설정

관련 링크: `https://www.npmjs.com/package/json-server`

선행 작업: `cd json-server`

### 설치

cmd: `npm install -g json-server`

### db.json 파일 생성

```
{
  "$schema": "./node_modules/json-server/schema.json",
  "posts": [
    { "id": "1", "title": "a title", "views": 100 },
    { "id": "2", "title": "another title", "views": 200 }
  ],
  "comments": [
    { "id": "1", "text": "a comment about post 1", "postId": "1" },
    { "id": "2", "text": "another comment about post 1", "postId": "1" }
  ],
  "profile": {
    "name": "typicode"
  }
}
```

### 실행

cmd: `npx json-server db.json`

# 2. 서버와 클라이언트 통신

1. 동기 통신:
   1. HTTP 통신 (동기 통신)
      - request(클라이언트) <-> response (서버)의 관계에서 응답이 오기 전까지 다른 프로그램 실행 불가
      - 요청과 응답이 발생 시 화면의 refresh 작업이 발생, 깜빡이는 증상 발생
   2. 비동기 통신
      1. Ajax - Asynchronous Javascript and XML (비동기 통신)
         - request(클라이언트) <-> response (서버)의 동작 중에도 다른 프로그램 구동 가능
         - 효율적, 화면 전체를 refresh 하지 않고 데이터를 전송하거나 받는 것이 가능
         - 클라이언트와 서버가 데이터 통신을 하기 위해서 XMLHttpRequest 객체를 이용하여 구현
         - XMLHttpRequest 객체를 이용하여 db.json 중 posts 데이터 가져오기를 해보기
         - 참고 1
